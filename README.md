# Debug_ESP
# Просмотр логов и диагностика ESP в Linux

Инструкция описывает подключение к последовательному порту платы ESP через `screen` для просмотра сообщений прошивки и диагностики состояния устройства. Для получения логов прошивка должна выводить сообщения в выбранный интерфейс.

## 1. Подготовка

1. Подключите плату к компьютеру USB-кабелем с поддержкой передачи данных.
2. Убедитесь, что установлена программа `screen`. В Debian/Ubuntu её можно установить командой:

   ```bash
   sudo apt install screen
   ```

3. Закройте другие программы, использующие этот последовательный порт, например монитор порта в IDE.

## 2. Определение порта

Имя устройства зависит от используемого USB-интерфейса, а не только от количества разъёмов на плате.

### Подключение через USB–UART-преобразователь

Для платы, подключённой через USB–UART-преобразователь, найдите доступные порты:

```bash
ls /dev/ttyUSB*
```

Пример результата:

```text
/dev/ttyUSB0
```

Такое подключение часто используется на платах с одним USB-разъёмом, а также через разъём UART на платах с двумя разъёмами.

### Подключение через встроенный USB-интерфейс ESP

Если плата поддерживает встроенный USB-интерфейс и подключена к соответствующему разъёму без внешнего USB–UART-преобразователя, проверьте порты:

```bash
ls /dev/ttyACM*
```

Пример результата:

```text
/dev/ttyACM0
```

> Правильный путь — `/dev/ttyACM0`, а не `/dev/ACM0`. Появление порта зависит от модели ESP и настройки USB-интерфейса.

Номер порта может отличаться: например, `ttyUSB1` или `ttyACM1`. Если подключено несколько устройств, сравните список портов до и после подключения платы.

## 3. Просмотр логов

Для подключения через USB–UART выполните:

```bash
screen /dev/ttyUSB0 115200
```

Для подключения через встроенный USB-интерфейс выполните:

```bash
screen /dev/ttyACM0 115200
```

Замените путь на фактический порт вашей платы. Параметр `115200` задаёт скорость соединения в бодах; для UART она должна соответствовать настройке прошивки.

После подключения в терминале будут появляться сообщения устройства. Если нужны стартовые сообщения, нажмите кнопку сброса `RESET`/`EN` после открытия порта. При сбросе встроенный USB-порт может отключиться и появиться заново; в таком случае повторно определите порт и запустите `screen`.

## 4. Выход из screen

Переключитесь на английскую раскладку. Во всех сочетаниях сначала нажмите `Ctrl+A`, отпустите клавиши, затем нажмите следующую букву **без Shift**.

### Отсоединиться, оставив сессию работающей

Нажмите `Ctrl+A`, затем `d`.

Вы вернётесь в командную строку, а сессия `screen` останется в фоне и продолжит удерживать порт. Это не сохраняет логи в файл.

Посмотреть список сессий:

```bash
screen -ls
```

Вернуться к единственной доступной отсоединённой сессии:

```bash
screen -r
```

Если сессий несколько, укажите идентификатор из вывода `screen -ls`:

```bash
screen -r <идентификатор_сессии>
```

Замените `<идентификатор_сессии>` реальным значением без угловых скобок.

### Закрыть подключение и освободить порт

Нажмите `Ctrl+A`, затем `k`. Если появится запрос подтверждения, нажмите `y`.

Команда закрывает текущее окно `screen` с подключением к порту. Если это единственное окно, сессия завершится. Перед прошивкой платы закройте подключение таким способом.

## 5. Если подключение не работает

| Симптом | Что проверить |
| --- | --- |
| Порт не найден | USB-кабель, выбранный разъём, поддержку USB-интерфейса платой и фактическое имя порта. |
| Ошибка `Permission denied` | Права пользователя на последовательный порт. |
| Порт занят | Монитор порта в IDE, другой терминал или оставшуюся в фоне сессию `screen`. |
| Вместо текста нечитаемые символы | Совпадение скорости UART с настройкой прошивки. |
| Окно пустое | Выводит ли прошивка логи, выбран ли нужный интерфейс и появляются ли сообщения после сброса платы. |

## 6. Краткая памятка

| Действие | Команда или клавиши |
| --- | --- |
| Найти USB–UART-порты | `ls /dev/ttyUSB*` |
| Найти ACM-порты | `ls /dev/ttyACM*` |
| Открыть USB–UART-порт | `screen /dev/ttyUSB0 115200` |
| Открыть ACM-порт | `screen /dev/ttyACM0 115200` |
| Отсоединиться от сессии | `Ctrl+A`, затем `d` |
| Показать сессии | `screen -ls` |
| Вернуться к сессии | `screen -r` |
| Закрыть подключение | `Ctrl+A`, затем `k`, подтвердить `y` |
